# 第一章　项目简介

## 1.1 这是什么产品

**凌田家校 · 家校共育系统**是一款服务学校与家庭的微信小程序。它的核心作用是：**让老师布置的亲子任务真正被家庭执行下去，并让每一次执行都留下看得见的成长痕迹。**

系统把「老师 → 家长 → 孩子 → 老师」这四方的动作连成了一个闭环：

```
老师布置本周亲子任务
        ↓
家长在手机上带着孩子一起完成，记录文字/打卡/照片/语音/视频
        ↓
老师批阅并给出针对性点评
        ↓
家长在「成长档案」里回看孩子这段时间的所有记录
        ↺ 回到起点，进入下一周
```

在这个闭环之上，系统还提供了三个"AI 助手"能力（**AI 只生成草稿，最终都要人来确认**）：

1. **AI 任务建议** —— 老师用一两句话描述学生近况，AI 结合学生家庭档案给出可执行的亲子任务草案。
2. **AI 任务草案** —— 家长反馈孩子的困扰，AI 整理成中性总结并起草任务草案，交老师确认。
3. **AI 点评草稿 / 通知草稿** —— 老师批阅作业、写家长通知时，AI 先生成一段文字，老师修改后再发出。

## 1.2 它解决什么问题

| 家长/孩子的困难 | 本系统怎么解决 |
| --- | --- |
| 老师布置的任务看不懂、不知道怎么做 | 任务卡里写清「共育目标 / 一起这样做 / 可以这样说 / 需要准备 / 提交什么 / 如果孩子不配合」六段内容，家长照着做即可 |
| 任务做完就没了，成长看不到 | 每次提交都会进入孩子的「成长档案」，加上老师的观察记录，形成可长期回看的时间线 |
| 想跟老师单独沟通但没渠道 | 内置「信息交流」，可与任何老师、家长、管理员一对一文字聊天 |
| 不知道孩子在学校的表现 | 老师用一句话语音记录，AI 自动整理成结构化观察并推送给对应家长 |
| 想反馈孩子的问题但说不清 | 「成长关注」表单引导家长描述具体表现，AI 整理后交老师确认，形成定制任务 |
| 孩子有心事不敢跟老师说 | 「我的小心事」提供匿名倾诉通道，由学校管理员逐条回复 |

## 1.3 谁在用：四种身份

系统按**身份**分配权限。同一个人用不同的账号登录，看到的内容完全不同。

| 身份 | 谁用 | 主要能做什么 | 登录后默认进入 |
| --- | --- | --- | --- |
| **家长** | 学生的父母或祖辈 | 查看并完成本周任务、提交记录、回看成长档案、看老师反馈、反馈孩子的情况 | 家长首页 |
| **学生** | 小学/初中学生本人 | 查看老师布置的任务并提交完成记录、查看老师点评、写「我的小心事」 | 我的任务 |
| **教师** | 班主任 / 任课老师 | 记录校园观察、发布任务、批阅提交、处理家长的成长关注、查看学生档案与班级数据 | 教师工作台 |
| **管理员** | 学校教务 / 心理老师 | 创建与维护全校账号、建立班级、查看任务进度与成长时间线、回复学生小心事 | 管理员工作台 |

> **重要**：账号由学校管理员统一创建，系统**不开放自助注册**。家长、学生、教师的账号都需要联系班主任或学校管理员开通。

### 各身份的底部导航

底部导航栏是每个角色主界面的固定入口：

| 身份 | 底部导航从左到右 |
| --- | --- |
| 家长 | 首页 · 教师反馈 · 成长档案 · 交流 · 我的 |
| 学生 | 我的任务 · 交流 · 我的 |
| 教师 | 工作台 · 学生 · 批阅 · 班级 · 交流 · 我的 |
| 管理员 | 概览 · 任务 · **AI 洞察**（中间凸起按钮）· 家校交流 · 我的 |

### 权限规则

- **未登录**访问任何页面，会自动跳回登录页。
- **身份不符**访问别人的页面，会弹出提示「当前账号无权访问此页面」，并自动送回你自己身份的工作台。
- 家长只能看到**自己孩子**的数据；教师只能看到**自己班上**学生与家长的数据；管理员看全校数据，但不能替教师发布内容。
- 学生端按未成年人个人信息处理，登录需监护人同意相关协议。

## 1.4 名词小抄

| 名词 | 意思 |
| --- | --- |
| **共育任务** | 老师布置给家庭、家长陪孩子一起完成的本周活动 |
| **草稿** | 填写了但还没正式提交的内容，可以继续编辑、也可以直接覆盖重填 |
| **正式提交** | 内容一旦提交就不能再修改，需在确认弹窗中二次确认 |
| **成长档案** | 孩子历次任务记录 + 老师观察 + 老师点评组成的时间线 |
| **成长关注** | 家长向老师反馈"孩子最近需要支持的具体表现" |
| **小心事** | 学生写给老师（实际由管理员处理）的心声倾诉 |
| **老师定制任务** | 老师根据某个学生的具体情况，单独为他/她生成的个性化任务 |
| **AI 洞察 / 草稿** | 由 AI 生成的参考内容，**不能直接当作结论使用**，需人工确认 |

## 2.3 核心业务流程

### 流程 A：每周共育任务闭环（最主要）

```
① 教师在「发布任务」里写好任务 → 发布给全班或指定某个学生
② 家长/学生在首页或消息通知中看到「本周任务」
③ 进入「任务详情」，按老师的说明带着孩子一起做
④ 用文字/打卡/图片/语音/视频任意方式记录 → 存草稿或正式提交
⑤ 教师在「批阅」里看到提交 → （可用 AI 生成点评草稿）→ 修改后发出点评
⑥ 家长在「教师反馈」「成长档案」里看到点评
```

### 流程 B：成长关注闭环（家校问题响应）

```
① 家长在「成长关注」表单描述孩子需要支持的具体表现（必填，至少 4 个字）
② 提交给老师；系统等待 AI 整理出一份"中性总结 + 任务草案"
③ 老师端「家长成长关注」列表收到这条反馈（状态：待老师处理）
④ 老师阅读家长描述 + AI 总结（AI 总结仅老师可见）
⑤ 老师选择：
     · 确认并推送 → 生成定制任务，推送到该学生的任务列表（状态：已生成定制任务）
     · 暂不采纳   → 填写回复原因告知家长（状态：老师已回复）
⑥ 家长在首页或「成长关注」列表看到处理结果
```

> **注意**：家长提交成长关注后**不会立刻**产生孩子的任务，必须等老师确认。

### 流程 C：校园观察记录闭环

```
① 教师在「今日校园观察」按住圆钮说一句话（或直接打字）
② 系统转写文字 → AI 整理成结构化观察 → 匹配到对应学生的家长
③ 记录进入「待校对清单」，标注"将推送给谁"
④ 教师核对名单与内容，可修改摘要与家长文案，也可删除不合适的记录
⑤ 点「确认无误」发送；当天未手动确认的记录，将在每天 18:00 自动发送
⑥ 家长在「通知中心」「成长档案」看到老师的观察记录
```

### 流程 D：学生心声闭环

```
① 学生在「我的小心事」写下心事（最多 500 字）→ 发送
② 管理员在「学生小心事」列表看到新提交 → 逐条回复（最多 500 字）
③ 学生重新进入「我的小心事」看到回复，首页提示消失
```

## 3.1 公共页面（所有身份共用）

### P-01　登录页

**页面用途**：用学校发放的账号和密码进入小程序，登录后自动进入你所属身份的工作台。

**入口路径**：打开小程序后的唯一入口；已登录状态下再次打开会直接跳过本页。

**页面路径**：`pages/login/login`

> 📷 **截图占位 P-01**
> - **文件名**：`screenshots/P-01-login.png`
> - **建议尺寸**：1080 × 1920 px（竖屏全屏，含状态栏）
> - **画面要点**：顶部品牌区（圆形 Logo +「凌田家校」+ 标语「家校共育 · 让成长被看见」）、登录卡片（「账号登录」标题 + 渐变装饰条）、账号输入框、密码输入框（含小眼睛图标）、错误提示条位置、「登 录」按钮、「家长账号由学校管理员统一创建」说明、协议勾选框
> - **建议补充一张**：协议弹窗打开状态（展示《用户协议》/《隐私政策》全文与「关闭 / 同意并继续」按钮）

**功能说明**

| 区块 | 内容 |
| --- | --- |
| 品牌区 | 圆形 Logo、大字「凌田家校」、标语「家校共育 · 让成长被看见」 |
| 登录卡片 | 大标题「账号登录」 |
| 账号输入框 | 提示语「请输入账号」，最多 30 个字符，左侧人形图标 |
| 密码输入框 | 提示语「请输入密码」，最多 64 个字符，右侧小眼睛可切换明文/密文 |
| 错误提示条 | 出错时才显示，红色底，显示具体原因 |
| 登录按钮 | 文案「登 录」，提交中变「登录中…」并置灰 |
| 协议说明 | 「家长账号由学校管理员统一创建，请联系班主任或学校管理员」 |
| 协议勾选 | 一个勾选框 + 文字「《用户协议》与《隐私政策》」，两份协议可分别点开阅读全文 |

**操作步骤**

1. 在「账号」框输入学校发放的账号。
2. 在「密码」框输入密码；点右侧小眼睛可核对密码是否输错。
3. （可选）点《用户协议》或《隐私政策》阅读全文——**不强制阅读**，弹窗随时可关。
4. 勾选同意协议。也可以在弹窗内直接点「同意并继续」完成勾选。
5. 点「登 录」。成功后提示「登录成功」，随后自动跳转到对应工作台。

**注意事项**

- 账号至少 3 个字符，密码至少 6 位。
- **必须勾选协议才能登录**，未勾选会提示「请先阅读并勾选同意《用户协议》与《隐私政策》」。
- 账号或密码错误时提示「账号或密码错误」；断网时提示「网络异常，请稍后再试」。
- 页面**没有**「注册」和「找回密码」入口，账号必须由学校创建。密码遗失请联系学校管理员重置。
- 登录成功时会记录你同意的协议版本与时间。

**功能说明**

- **班级列表卡片**：点卡片主体展开/收起详情（文字在「详情 ›」与「收起」间切换）；右侧「编辑」按钮单独点击，不会触发展开。展开后显示三行成员清单：「教师」（姓名标签，负责教师后带「· 负责」）、「学生」（姓名 + 年级）、「家长」（姓名标签）。
- **创建班级表单**：
  - 「班级名称 *」（提示「如：四年级一班」）
  - 「年级」（提示「如：四年级」）
  - 「负责教师 *」（提示「该班学生与家长的提交会归入这位教师的端」，下方为教师可选标签）
  - 三个可多选区：「任课教师」「学生」（下方提示「已选 X 人 · 学生绑定的家长会一并纳入班级」）、「家长」
- **编辑班级表单**：在基本信息之外，改为三个成员管理区，每区含「当前成员」标签块（带「×」可移除、负责教师无删除按钮）+「添加 XX」区。

**操作步骤**

1. 点「+ 创建班级」（若系统里还没有教师账号，会提示「请先创建教师账号」）。
2. 填写班级名称、年级，点选负责教师（必填）。
3. 在「任课教师」「学生」「家长」三个区勾选成员（可多选/取消）。
4. 点「创建班级」。
5. **编辑已有班级**：点卡片展开查看成员；点「编辑」进入编辑态，修改名称/年级/负责教师，用「×」移除成员、点「+ 姓名」添加成员，最后点「保存修改」。

**注意事项**

- **必须先有教师账号才能创建班级**，否则提示「请先创建教师账号」。
- **「班级名称」和「负责教师」为必填**。
- 选定负责教师后，该教师会**自动加入任课教师名单**。
- 如果把当前负责教师从任课教师中取消勾选，**负责教师会被一并清空**，需重新选择。
- **移除正在担任负责教师的教师会被拦截**，提示「请先更换负责教师后再移除」。
- **创建时勾选学生，其绑定的家长会自动一并纳入班级**。

# 第四章　使用注意事项

## 4.1 账号与登录

1. **账号由学校统一创建，系统不开放自助注册。** 请联系班主任或学校管理员开通账号。
2. **密码遗失请联系学校管理员重置**，小程序内没有「找回密码」入口。
3. **每次登录都需要勾选同意《用户协议》与《隐私政策》**，这是合规要求，不设阅读门槛，可随时在「我的」页查阅全文。
4. **身份决定你看到的内容**。用家长账号访问教师页面会提示「当前账号无权访问此页面」并自动送回家长首页，这是正常的保护机制。
5. **退出登录需二次确认**，退出后本机登录状态被清空。

## 4.2 关于 AI 生成内容

这是本系统最需要留意的一点，请务必记住：

> **AI 生成的任何内容（任务建议、任务草案、点评草稿、家长通知、洞察结论）都是「草稿」或「参考」，最终都要由人确认后才生效。**

| 场景 | AI 做什么 | 人必须做什么 |
| --- | --- | --- |
| 教师发布任务 | 一键生成任务草稿 | 人工检查修改后点「确认发布」 |
| 教师批阅作业 | 生成点评草稿 | 人工修改后点「发送点评」 |
| 家长提交成长关注 | 整理成中性总结 + 任务草案 | 老师确认后才生成定制任务 |
| 教师发通知 | 生成催交通知模板 | 人工过目后写入通知中心 |
| AI 洞察 | 生成分析结论 | 仅供参考，页面标注「AI 生成内容仅供参考」 |

另外请注意：

- **AI 洞察页面标注「AI 生成内容仅供参考」，不能直接当作结论或对家长的话术照搬。**
- 当家长描述中出现「需专业支持」红色徽标时，页面会明确提示：**不建议仅依靠家庭任务处理，应先由班主任或学校专业人员进一步了解。**
- AI 服务不可用时，系统会自动降级为「本地规则分析」，功能仍可正常使用，页面会明确说明当前状态。

## 4.3 录音与附件

| 项目 | 限制 |
| --- | --- |
| 语音录制单次时长 | 最长 60 秒 |
| 视频录制单次时长 | 最长 60 秒 |
| 语音转文字 | 单次最长 60 秒；低于 0.5 秒视为误触，会提示「说话时间太短，已取消」 |
| 附件数量 | 最多 6 个 |
| 单个附件大小 | 不超过 15MB |
| 支持的附件类型 | 图片、语音、视频 |

- **首次录音需要麦克风授权**，会弹出「需要麦克风权限」，请点「去设置」允许。
- 语音功能是**可选的**，未授权或服务不可用时，直接输入文字同样可以完成录入和提交。
- **上传失败不会加入本次提交**，会弹窗提示，请重试后再提交。
- 教师端「今日校园观察」与「AI 洞察」的录音是**两种不同的交互**：前者是「点击开始说 → 再点停止」，后者是「**长按说话、松开发送**」。

## 4.4 内容提交相关

| 事项 | 规则 |
| --- | --- |
| **正式提交不可修改** | 提交前有二次确认弹窗；提交后页面锁定，只能查看 |
| **草稿可以覆盖** | 同一任务只能保存一条草稿，再次保存会覆盖之前的内容 |
| **不能重复提交** | 同一任务正式提交后再次提交会提示「该任务已提交，请勿重复提交」 |
| **提交必须有内容** | 打卡模式至少勾一项；其他模式需填写文字或添加附件 |
| **文字记录上限** | 4000 字 |
| **成长关注描述** | 必填，至少 4 个字，最多 1200 字 |
| **小心事** | 必填，最多 500 字 |
| **点评** | 必填，最多 500 字；标签最多 5 个，用逗号分隔 |
| **老师回复家长** | 最多 500 字；选择「暂不采纳」时为必填 |
| **通知与公告** | 最多 1200 字 |
| **家长通知中心单次加载** | 最近 20 条 |
| **心事单次加载** | 学生端最近 50 条；管理员端最近 100 条 |

## 4.5 隐私与数据

- **家长查看范围**：只能看到自己孩子的数据。
- **教师查看范围**：只能看到自己班上学生与家长的数据（由管理员在「班级管理」中划分）。
- **管理员查看范围**：可看全校数据，但**不能代教师发布任务或发送通知**。
- **AI 总结仅教师可见**，家长和管理员在成长关注列表里都看不到。
- **学生小心事**：页面上明确写着「提交内容其他人不可见　我们对你的信息保密」。
- **亲子参与分析**：家长可随时在「亲子参与」页关闭「关注分析」开关，关闭后系统不再统计陪伴行为；「数据说明」标签明确列出系统会看与不会看的数据。
- **家长通知中心**：「从本机列表隐藏」只影响本机显示，**不会删除服务器上的通知，也不等于已读**。
- **微信订阅消息为一次性授权**：授权一次对应一次提醒，需要更多提醒需再次点「开启」；学校未配置时站内通知仍正常收取。

## 4.6 状态含义速查

| 状态 | 含义 | 谁能看到 |
| --- | --- | --- |
| 待完成 | 任务已发布，尚未开始记录 | 家长、学生 |
| 草稿待提交 | 已保存草稿，尚未正式提交 | 家长、学生 |
| 待老师点评 | 已正式提交，等待老师批阅 | 家长、学生 |
| 已完成 | 老师已点评，本周任务闭环 | 家长 |
| 待老师处理 | 家长已提交成长关注，等老师确认 | 家长、教师、管理员 |
| 已生成定制任务 | 老师已确认并推送定制任务 | 家长、教师、管理员 |
| 老师已回复 | 老师暂不采纳，但已回复家长 | 家长、教师、管理员 |
| 待点评 | 该条提交还没有老师点评 | 教师 |
| 已点评 | 该条提交已有老师点评 | 教师 |
| 已完成 / 草稿 / 未开始 | 学生维度的任务完成情况 | 教师、管理员 |
| 未查看 / 已查看 | 管理员是否已看过学生小心事 | 管理员 |
| 回复未读 / 回复已读 | 学生是否已看过管理员的回复 | 管理员 |

## 4.7 常见问题

**Q1：登录时提示「账号或密码错误」怎么办？**
请确认账号与密码是否正确（注意大小写与空格）。仍无法登录请联系学校管理员核对或重置密码。小程序不提供自助找回密码。

**Q2：登录时提示「请先阅读并勾选同意《用户协议》与《隐私政策》」？**
请勾选登录页下方的协议勾选框。也可以点开《用户协议》或《隐私政策》阅读后，在弹窗内点「同意并继续」直接完成勾选。

**Q3：为什么我的页面和别人不一样 / 提示「当前账号无权访问此页面」？**
系统按账号身份分配权限。请用对应的账号登录：家长账号看家长端、教师账号看教师端、管理员账号看管理员端。

**Q4：家长提交了成长关注，为什么孩子的任务列表里没有变化？**
这是设计如此。家长提交成长关注后，系统先生成 AI 总结与任务草案，**必须等老师确认并推送后**，定制任务才会出现在孩子的任务列表里。你可以在「成长关注 → 我的反馈」查看状态变化。

**Q5：为什么老师看不到某个学生？**
教师只能看到自己班上学生与家长的数据。请管理员在「班级管理」中把该学生（或其家长）加入对应班级，并确认已设置负责教师。

**Q6：为什么我的通知发不出去？**
若提示「微信订阅消息尚未配置」，说明学校侧还没配置微信推送，**站内通知仍然会正常收取**。同时请确认对应家长已授权订阅提醒（一次性授权，需多次提醒时要再次授权）。

**Q7：录音没反应 / 提示「未获得麦克风权限」？**
请在手机「设置 → 小程序 → 权限」中允许使用麦克风。也可以直接用文字输入完成记录，语音不是必需的。

**Q8：附件上传失败怎么办？**
请检查单个文件是否超过 15MB、附件数量是否超过 6 个。上传失败的附件不会加入本次提交，请删除后重试。

**Q9：任务提交后还能修改吗？**
不能。正式提交前有二次确认弹窗，提交后页面即锁定。如果还没提交，建议先点「存草稿」，确认内容无误后再正式提交。

**Q10：为什么「成长关注」页面底部导航没有高亮？**
该页面是从首页悬浮按钮进入的独立表单页，不属于底部导航的五个主标签，属正常现象。

**Q11：管理员在 AI 数据看板里为什么没有「写入家长通知中心」按钮？**
管理员为**只读模式**，可以生成和复制通知模板，但不能代教师发送。需要发送时请由教师本人操作。

**Q12：删除账号会不会把数据都删掉？**
会。删除教师、学生或家长账号后，该账号立即失效，登录会话、绑定关系及相关记录会被清理，且**此操作不可撤销**。管理员端删除按钮为红色并有二次确认弹窗，执行前请务必谨慎。

**Q13：页面显示「加载中…」一直不结束？**
可能是网络波动。请下拉刷新重试；若持续异常，请联系学校管理员。

**Q14：孩子的心事别人能看到吗？**
「我的小心事」页面明确承诺「提交内容其他人不可见　我们对你的信息保密」。只有负责处理的管理员可以查看并回复。

**Q15：AI 建议的内容能直接发给家长吗？**
**不可以直接照搬。** 系统内 AI 生成的一切内容都需人工确认后才生效，请务必先阅读、修改，再决定是否使用。
