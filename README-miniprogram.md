## 三、手机预览时报「网络异常」——原因与解法

### 原因

小程序在**真机**上会强制校验 `request` 合法域名（模拟器不校验）。当前后端是
`https://home-school-04zi.onrender.com`，它不在你小程序的合法域名列表里，
`wx.request` 直接被微信拦截，前端就显示「网络异常，请稍后再试」。

代码里已把这类失败单独识别为 **「域名未加入合法域名白名单」**（见 `utils/api.js` 的 `fail` 分支），
重新编译后在手机控制台能看到具体 `errMsg`。

### 马上能用的两个办法（仅限开发调试）

1. **用「真机调试」，不要用「预览」**
   开发者工具顶部点「真机调试」→ 扫码，手机上会进入调试模式，**跳过域名校验**。
2. **手机上手动开调试**
   小程序右上角 `⋯` → 打开调试 → 小程序自动重启，之后同样跳过域名校验。
   关掉调试就会恢复校验。

> 「详情 → 本地设置 → 不校验合法域名」只对**模拟器**生效，
> 扫码「预览」出来的包在手机上仍然会校验，这是很多人踩的坑。

### 正式上线必须解决（重要）

微信公众平台的服务器域名要求 **HTTPS + 已完成 ICP 备案**。
`home-school-04zi.onrender.com` 是 Render 提供的境外域名，**没有 ICP 备案，很可能加不进白名单**。
也就是说这个后端地址只能用于开发调试，正式发布必须换后端地址：

- 方案 A：把 `server.js` 部署到国内云（腾讯云 / 阿里云），绑定你已备案的域名
- 方案 B：用已备案域名做反向代理，转发到现有 Render 服务

换好后：公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名 → **request 合法域名** 添加新地址，
并同步修改 `miniprogram/utils/api.js` 顶部的 `API_BASE`。

> Render 免费实例会休眠，**冷启动约 15 秒**（实测热状态 1~3 秒），请求超时已放宽到 30 秒。

## 六、已知限制（后端能力决定，非前端缺陷）

1. **无文件上传接口**：图片附件走「压缩 → base64 data URI」，单页最多 3 张，单张控制在 3 MB 内（后端限制单附件 15 MB、请求体 6 MB）。
2. **无分页**：后端列表都是 limit-only，多处硬编码 LIMIT（20/50），不做翻页。
3. **AI 对话不支持流式**：`wx.request` 不支持 SSE，已走非流式接口。
4. **管理员受后端限制**：`canAccessChild` 不放行 `admin`，管理员访问按 childId 过滤的接口会 403；时间线走的是 admin 专用看板接口，不受影响。
5. **班级任务每周仅一条**：重复发布会覆盖本周任务；个性化任务可多条。
6. **调成长档案会清空未读反馈数**：`/api/timeline` 的后端副作用，属原站既有行为。
